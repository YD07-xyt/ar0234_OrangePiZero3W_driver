## 交叉编译环境配置

### 1. [armbian构建工具](https://github.com/armbian/build.git)

```sh
git clone --depth=1 --branch=main https://github.com/armbian/build
```

```sh
cd ./build
export http_proxy=http://host.docker.internal:7897
export https_proxy=http://host.docker.internal:7897

./compile.sh \
  BOARD=orangepizero3w \
  BRANCH=vendor \
  RELEASE=jammy \
  BUILD_MINIMAL=yes \
  BUILD_DESKTOP=no \
  KERNEL_CONFIGURE=no
```
BOARD=orangepizero3w：指定目标开发板为 Zero 3W

BRANCH=vendor	: 源码来源芯片/板卡厂商

RELEASE=jammy：Ubuntu 22.04 (Jammy)

BUILD_MINIMAL=yes 与 BUILD_DESKTOP=no：构建无桌面的最小化系统

KERNEL_CONFIGURE=no：跳过内核配置菜单，使用默认配置

#### 常见问题

##### 1. 编译失败
```sh
# 1. 安装 qemu-user-static 和 binfmt-support
sudo apt update
sudo apt install -y qemu-user-static binfmt-support
# 2. 更新并启用 binfmt 注册
sudo update-binfmts --enable qemu-aarch64
sudo systemctl restart docker
```
